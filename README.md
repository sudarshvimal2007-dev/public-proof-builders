# Build Your Edge

# ABTalks — Vibe Coding Hackathon Master Build Prompt

Build a polished, production-quality **mobile-first web experience for ABTalks**, a 60-day public learning and coding challenge platform for Indian college students.

The product helps students:

* Learn consistently for 60 days

* Build something every day

* Submit GitHub proof of work

* Share daily progress on LinkedIn

* Build a public learning record

* Earn badges and achievements

* Maintain a streak

* Compete on a leaderboard

* Build credibility that can give them an edge with recruiters

The existing product works but has never been properly designed. This redesign should make ABTalks feel like a **premium modern SaaS product with a developer-focused identity, subtle gamification, strong motion design, and excellent mobile UX.**

---

# CORE PRODUCT IDEA

ABTalks is not simply a coding challenge.

It should communicate:

> **Learn → Build → Prove → Share → Get Recognized**

The core philosophy is:

> **Don't just learn. Build in public.**

Primary brand message:

> **Build Your Edge.**

Use dynamic hero copy where the phrase after "Build" changes smoothly:

* Build Publicly.

* Build Daily.

* Build Consistently.

* Build Your Proof.

* Build Your Edge.

The changing text should use a smooth, premium transition such as vertical slide + blur/fade. Avoid a cheap typewriter effect.

# DESIGN DIRECTION

Overall aesthetic:

**Premium + Futuristic + Gamified Modern SaaS**

Reference the design quality and cleanliness of modern SaaS products, but do NOT copy any existing website.

The interface should feel:

* Premium

* Modern

* Developer-focused

* Motivating

* Clean

* High-tech

* Slightly competitive

* Visually memorable

* Recruiter-friendly

Avoid:

* Excessive neon

* Childish gamification

* Crypto aesthetics

* Generic hacker aesthetics

* Excessive terminal/code decoration

* Clutter

* Random animations

* Poor contrast

* AI-generated-looking UI

The interface should look deliberately designed.

# COLOR SYSTEM

Base background:

`#121212`

Use a dark gray/black foundation.

Secondary surfaces should use slightly lighter dark grays.

Use a **subtle green ambient glow** throughout the desktop experience.

The green should be restrained and premium, NOT bright neon.

Use green primarily for:

* Progress

* Streaks

* Success

* Active states

* Achievement highlights

* Ambient background lighting

* Important positive statistics

Use neutral whites/grays for most typography.

Use subtle gradients where appropriate.

Support a complete **dark/light theme toggle**.

Dark mode must be the default.

The theme toggle should be located in the desktop navbar and use a subtle glassmorphism treatment.

---

# TYPOGRAPHY

Use a modern SaaS typography system.

Prioritize:

* Excellent readability

* Large strong headings

* Clear hierarchy

* Comfortable line height

* Generous spacing

* Strong numerical typography

* Clean labels

Use a modern sans-serif font.

Do not overuse futuristic or monospace fonts.

Developer aesthetics can appear in small labels or technical elements, but the main typography should remain professional and readable.

# MOBILE ANIMATION RULES

Reduce heavy desktop effects on mobile.

Disable/reduce:

* 3D laptop

* Heavy particles

* Mouse-following effects

* Complex parallax

* Large animated backgrounds

* Heavy blur

* Complex 3D transforms

Keep:

* Simple reveal

* Progress animations

* Counter animations

* Button micro-interactions

* Streak animation

* Small card transitions

* Lightweight gradients

Performance is more important than decorative effects.

Respect `prefers-reduced-motion`.
